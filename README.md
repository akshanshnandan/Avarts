Avarts
Avarts is a Java-based running analytics web application that helps runners track their workouts and understand their progress over time.
Project Goal
I run regularly and want a straightforward way to see how my mileage and pace change over time. RunLog will let users record their runs in one place and view meaningful statistics and progress toward a weekly goal.
MVP Scope (Version 1.0)
- Log a run with its date, distance, and duration using a web form.
- Save runs in a persistent database and display workout history.
- Calculate pace for individual runs, weekly mileage, and average pace.
- Show weekly mileage trends on a dashboard chart.
- Set a weekly mileage goal and display progress toward it.
Future Plans (Version 2.0)
- User accounts and authentication.
- Integration with Strava or other fitness services.
- Advanced analytics, including personal records and pace predictions.
